## 2024-06-19 - Memoize Context Values
**Learning:** In Next.js applications, not memoizing a global Context's `value` object (like `CartContext.Provider value={{...}}`) creates a new object reference on every render of the Provider. This causes all consuming components to re-render needlessly, which can be a severe performance bottleneck, especially if the context is widely used across the application. Also, derived states such as array reductions for subtotal and item count should be memoized to prevent recalculation on unrelated re-renders.
**Action:** Always wrap context `value` objects and expensive derived states (like array reductions) in `useMemo`, paying attention to correctly list their dependencies. This is particularly crucial for global state providers in React/Next.js.
